# Проверка расчётной программы — v5

## Что исправлено

1. Одно граничное условие теперь определяет оба значения: `N(0)` и `N(4l)` выводятся в редакторе схемы. В расчётном модуле есть `Calculator.boundary_values()`.
2. Программа использует уравнение равновесия (сила положительна вправо):
   `N(4l) = N(0) − ΣFz − Σ(qz·Δz)`, где учитываются только нагрузки внутри стержня. Сосредоточенная сила на свободном торце задаёт начальное (или конечное) условие и повторно не суммируется.
3. В ручном режиме можно задать **либо** `N(0)`, **либо** `N(4l)`: другое находится из равновесия. Если результат противоречит силе на свободном торце, расчёт отклоняется с объяснением.
4. У пользовательских нагрузок есть редактируемые координаты: `z/l` для силы, `от/l` и `до/l` для распределённой нагрузки. Допускаются дробные множители и координаты внутри стержня. Координаты проверяются.
5. При визуальной сверке с оригинальным рисунком из приложения 2 обнаружены и исправлены неверные координаты сосредоточенных сил в **схемах №1, 9, 15, 18, 25**. В тесты добавлена проверка этих координат.
6. Отрицательные, бесконечные и неопределённые параметры отвергаются вместо молчаливого расчёта.

## Числовой пример (проверка двумя способами)

Опора справа, длина 4l, P = 10 кН, q = 3 кН/м, l = 1 м:
- на свободном левом торце сила +P;
- на [l, 2l] распределённая нагрузка +q;
- при z = 2l действует сила −2P.

Имеем `N(0) = −10 кН` и `N(4l) = −10 − (3·1 − 20) = 7 кН`.
В программу можно передать любое одно из этих двух условий; она вычисляет второе. Если указать не согласованное с нагрузками условие, программа сообщает об ошибке.

## Тесты

```powershell
python -m unittest discover -v
```

23 теста, все пройдены. Среди них проверка обоих граничных условий на 900 сочетаниях (30 схем × 30 строк исходных данных), физической согласованности ручных Г.У., нестандартных координат, исходного примера преподавателя, двух студенческих схем, прочности и жёсткости.

**Ограничения:** GUI не запускался в этой среде ввиду отсутствия PyQt6. Тесты проверяют расчётные компоненты и Word, код GUI проходит синтаксическую проверку. Результаты не заменяют физическую проверку вручную новой произвольной схемы; расчёт предназначен для прямого стержня с одной закреплённой стороной, постоянным E и постоянным поперечным сечением. Статически неопределимые системы, устойчивость и динамика не реализованы. Точность геометрического переноса всех рисунков, кроме явно перепроверенных, не сертифицирована.
