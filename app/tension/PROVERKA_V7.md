# Проверка программы Sapromat-calk v7

## Изменение интерфейса граничных условий

- Стандартные 30 схем: опора задаётся схемой, граничные условия вычисляются автоматически. Полей для ввода нет.
- Пользовательская схема: пользователь выбирает положение опоры; программа определяет, какой торец свободен. При ручном вводе появляется только одно поле: N(0) для опоры справа, N(4l) для опоры слева.
- Второе условие вычисляется по статическому равновесию: N(4l)=N(0)-ΣFz, где ΣFz включает силы внутри стержня и интегралы распределённых нагрузок. Сосредоточенная сила на свободном торце задаёт первое условие, а сила на закреплённом торце учитывается при определении реакции.
- Если введённое значение противоречит торцевой нагрузке, расчёт прерывается с объяснением ошибки.

## Проверки
- 30 автоматических тестов (`python -m unittest discover -v`) — успешно.
- Граничные условия проверены на 900 комбинациях. Сверяются начальные значения на свободных торцах, баланс внутренних сил и восстановление обратным вычислением.
- Word-экспорт успешно создан для всех 30 схем с одноимённой строкой данных (30 DOCX).
- Отдельно проверены три известных примера: схема 17 (Ника), схема 21 (Горбачёв), схема 22 (образец преподавателя).

## Оформление Word
- Титульная страница построена из исходного DOCX преподавателя (страница 2), а не воссоздана приблизительно.
- Полный вариант состоит из 4 частей: первые две от задачи 3, последние две для задач 1,2,4–10. Программа подставляет только известные две последние части, не сочиняя первые.
- На следующей странице: Дано, таблица исходных данных со схемой, Требуется, Решение.
- Затем подробный расчёт, восемь граничных значений, схема и эпюра, подбор и проверка прочности.

## Оставшиеся ограничения
- Расчётная модель — стержень из четырёх участков с одной заделкой, осевые сосредоточенные силы и равномерные распределённые нагрузки. За пределами модели нельзя заявлять гарантию.
- В контейнере отсутствует PyQt6, поэтому графическое окно не запускалось. Проверены Python-синтаксис, расчётное ядро и генерация DOCX; проверить переключатели на пользовательском ПК нужно отдельно.
- Word-отчёты рендерились в LibreOffice, но совпадение переносов страниц при другой версии Microsoft Word может немного отличаться.
- Универсальная формула Маколея корректна для пользовательских нагрузок. Текстовая детализация по четырём стандартным участкам при нагрузках внутри участка не заменяет полный набор точек эпюры.
