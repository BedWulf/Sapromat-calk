# Кручение круглого вала — задача №2 ОмГТУ (2026/27)

Автономная программа на Python/Tkinter для расчёта кручения четырёхучастного круглого вала, с готовыми вариантами преподавателя и свободным ручным вводом. Может работать без интернета после сборки в один EXE для Windows.

## Главное отличие от первой версии

Теперь доступны **30 строк исходных данных** из приложения 1 и **30 схем нагружения** из приложения 2 методички «2. Пояснения к задаче на кручение». Скриншот каждой схемы взят из предоставленной пользователем методички, чтобы можно было визуально сверить выбор. Нагрузки и расположение заделки для стандартных схем выставляются автоматически.

**Важно:** полное обозначение варианта имеет вид `X-X-Y-Z`: `Y` — строка исходных данных, `Z` — номер схемы. Первые два числа относятся к задаче №3 и вводятся отдельно на титульном листе. Таблица задачи №2 содержит величины `L` и `m`.

**Ручной режим** («Своя схема») включает ввод четырёх длин, распределённых моментов, пяти сосредоточенных моментов, типа закрепления, наружных диаметров и коэффициента полости. Никаких значений Mк(0), Mк(4l) вводить не требуется: они определяются исходя из торцевых нагрузок и равновесия.

### Расчёт и оформление

- Глобальное равновесие, реакция заделки, граничные условия на свободном конце.
- Формулы Mк(z) на четырёх участках, таблица восьми значений и эпюра со скачками и штриховкой.
- Расчёт опасного сечения.
- **Подбор по прочности для круглого и кольцевого сечения** при `d/D=0,5`, сравнение веса. Значение [τ]=90 МПа взято из методички, используется приближение `Wρ=0,2·D³·(1−k⁴)` в отчёте.
- Дополнительные расчёты углов закручивания/жёсткости (не являются основным требованием преподавателя для задачи №2).
- Титульный лист ОмГТУ; все данные студента можно изменить на вкладке «Титульный лист».
- Экспорт DOCX, PNG и JSON.

### Контрольный пример

Схема решения преподавателя: `L=10 кН·м`, `m=5 кН·м/м`; сосредоточенный `+L` при `z=l`, распределённый `−3m` на участке II и `+2m` на участке IV. Вычисленные восемь значений: `5, 5, -5, 10, 10, 10, 10, 0` кН·м. Расчёт прочности: круглый `85 мм`, кольцевой `D=86 мм, d=43 мм`.

**Не путать** этот пример с рисунком стандартной схемы №11 в приложении 2: в нём на участке II указан `m`, а в расчёте преподавателя `3m`. Пример вынесен отдельной кнопкой.

### Запуск с установленным Python

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python main.py
```

### Сборка в один EXE

На Windows 10/11 x64 с Python 3.12 и интернетом запустите `build_exe.bat`. Он установит зависимости в локальное виртуальное окружение, выполнит тесты, соберёт `dist\Raschet_Krucheniya.exe` и запустит проверку сохранения DOCX, построения графика и работы Tk из **собранного** EXE.

На рабочий компьютер переносится только `dist\Raschet_Krucheniya.exe`. Python, интернет, исходный код и шаблоны рядом не нужны. Для открытия сохранённого DOCX понадобится Word или совместимый редактор. Приложению нужны права на запись во временный каталог Windows. Антивирус организации может блокировать неподписанные приложения.

## Границы применимости

Один заделанный конец, круговое/кольцевое поперечное сечение, линейно-упругое малое кручение, постоянная распределённая интенсивность на каждом участке. Две заделки, другие сечения, концентрация напряжений и пластическое кручение не моделируются.

Расчётное ядро и интерфейс проверены под виртуальным дисплеем Linux, однако готовый **Windows EXE здесь не собирался**: его обязательно нужно собрать и испытать на Windows. Число прогнанных тестов не означает формальной независимой сертификации каждого рисунка методички.
