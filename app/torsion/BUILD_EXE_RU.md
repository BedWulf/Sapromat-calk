# Сборка одного офлайн EXE для Windows

1. На **Windows 10/11 x64** установите **Python 3.12 x64** с официального python.org. При установке включите **Add Python to PATH**.
2. Распакуйте весь ZIP архив на домашний компьютер. Не запускайте `build_exe.bat` внутри архива.
3. При наличии интернета запустите `build_exe.bat` двойным щелчком.
4. Ждите надписи **SUCCESS**. Готовый файл: `dist\Raschet_Krucheniya.exe`.
5. Скопируйте на флешку **только `Raschet_Krucheniya.exe`**. На рабочей Windows Python, библиотеки и интернет не требуются.

При сборке включаются изображения всех стандартных схем из папки `assets`. `build_exe.bat` проводит автоматические тесты и после сборки запускает `EXE --self-check` (проверяет создание Word, график и работу оконной системы).

Технические особенности: один EXE при запуске временно распаковывается в `%TEMP%`. Необходим доступ на запись во временную папку. На управляемой корпоративной Windows может сработать защита SmartScreen/антивирус; при блокировке обратитесь к администратору, не отключайте защиту.

Если сборка не удалась, проверьте версии Python/архитектуру и полный вывод консоли. PyInstaller не кросс-компилирует Windows EXE из Linux. На Windows 7 запуск PyInstaller/Python 3.12 не поддерживается.

Для теста готового EXE без графической оболочки можно вручную выполнить:

```powershell
.\dist\Raschet_Krucheniya.exe --self-check .\dist\check.txt
Get-Content .\dist\check.txt
```

В `check.txt` должно содержаться `SUCCESS:`. Это тест пакета, а не подтверждение всех элементов Windows UI.
