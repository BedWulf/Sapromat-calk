# Сопротивление материалов — ОмГТУ

**Актуальная объединённая программа** с заданиями №1 (растяжение–сжатие) и №2 (кручение) находится в [каталоге app](app/).

- [Инструкция и сборка Windows EXE](app/README.md)
- [Главная точка входа](app/main.py)
- [Тесты и контрольные примеры](app/tests/)
- [Оригинальные шаблоны отчётов](app/teacher_templates/)

Для запуска из исходников на Windows: Python 3.12, `pip install -r app/requirements.txt`, затем `python app/main.py`.
Для сборки одного EXE запустите `app\build_exe.bat`. Результат: `app\dist\Sopromat_OMGTU.exe`.

Предыдущая версия калькулятора растяжения-сжатия сохранена в корне репозитория до проверки новой версии на Windows.
